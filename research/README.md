# Research inputs

Each week, create a folder named `YYYY-Www` (ISO week, e.g. `2026-W47`) with two subfolders.

## `transcripts/`: 10-20 viral videos
One file per video, e.g. `01-creatorname.md`. Put a short header at the top so the researcher can weigh the video:

```
creator: @handle
followers: 19.6K
views: 783K
likes: 52K
saves: 6.1K
shares: 2.4K
length: 0:41
first-frame text: "..."
---
<paste transcript here>
```

Leave out any numbers you don't have. Pick videos in or near the self-improvement lane, and include a couple of the same creators' *average* posts so winners can be compared against them.

## `analytics/`: your own numbers
Drop your TikTok export (CSV) or screenshots, or a quick notes file per post:

```
post: <short title> — posted <date>
views / likes / saves / shares / comments:
avg watch time / % watched / % finished:
new followers:
where most viewers left (retention graph):
```

## After posting
Add one row per post to `results-log.md`. Add new stories (and anything you post or cut) to `story-bank.md`.
